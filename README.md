# Personal Portfolio Website

## About the Project
This is my personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my education, technical skills, projects, and contact information in a professional and user-friendly design.

## Technologies Used
- HTML5 – Used to structure the website.
- CSS3 – Used for styling, layout, animations, and responsive design.
- JavaScript – Used to add interactivity and dynamic functionality.

## Features
- Personal introduction
- About Me section
- Education details
- Technical skills
- Projects showcase
- Contact information
- Responsive website design
- Attractive user interface

## Purpose
The purpose of this project is to create a professional online portfolio to showcase my technical skills, academic projects, and personal information.

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Structure
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Interactive functionality
